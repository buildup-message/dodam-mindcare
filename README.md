# 도담마인드케어 CRM 시스템 (Phase 1)

구글 스프레드시트와 Apps Script를 백엔드로 사용하고, 순수 HTML/JS로 구성된 프론트엔드 스태프 페이지를 제공하는 CRM 시스템입니다.

## 폴더 구조
- `apps-script/`: 백엔드 Google Apps Script 소스코드.
- `staff/`: 스태프용 프론트엔드 웹 애플리케이션 소스코드.

## 기능 구성
- **주간 일정**: 구글 캘린더 연동 및 방 중복 확인
- **예약 관리**: 상담 예약 생성/수정/취소
- **내담자 관리**: 내담자 등록 및 메모 이력 누적
- **결제 기록**: 결제 금액(할인, 바우처 지원금/본인부담금) 관리 및 커버 종료일 추적
- **결제 요청**: 페이히어 링크결제 발송 상태(대기/발송함/완료) 추적
- **정합성 점검**: 캘린더와 시트 간의 데이터 불일치 자가 점검
